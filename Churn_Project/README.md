# Customer Churn Prediction

## Project Overview
This Machine Learning project predicts whether a bank customer is likely to leave the bank using customer information and historical data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- Streamlit

## Features
- Data Cleaning
- Exploratory Data Analysis
- Categorical Data Encoding
- Feature Scaling
- Model Training
- Model Evaluation
- Customer Churn Prediction
- Interactive Web Application

## Machine Learning Model
Logistic Regression

## How to Run

1. Install dependencies:
   `python -m pip install pandas numpy scikit-learn streamlit`

2. Run the application:
   `python -m streamlit run app.py`

## Project Files
- `main.py` – Model training and evaluation
- `app.py` – Streamlit web application
- `churn_model.pkl` – Trained model
- `scaler.pkl` – Feature scaler
- `feature_names.pkl` – Model feature names
- `Churn_Modelling.csv` – Dataset

## Objective
To identify customers who may leave a bank and help businesses improve customer retention.
